## 🚀 Capstone Full-Stack Project: CareerConnect (Internship & Job Portal)
A complete, responsive full-stack MERN application built with **HTML5, CSS3, JavaScript, ReactJS, NodeJS, ExpressJS, and MongoDB**, deployed on **Vercel**.

📁 **Directory:** [`/internship-job-portal`](./internship-job-portal)  
🌐 **Live Deployment:** [https://web-application-bzet0g6hk-debatra.vercel.app/](https://web-application-bzet0g6hk-debatra.vercel.app)  
📖 **Comprehensive Documentation:** [Read the Full README & API Specs](./internship-job-portal/README.md)  


### Key Capabilities:
1. **🏢 Companies Post Job Opportunities:** Recruiter dashboard with rich posting modal (stipend, duration, openings, skills tags, perks, deadlines) and applicant reviewer.
2. **🎓 Students Create Profiles:** Academic profile editor (university, degree, CGPA, graduation batch), dynamic skill tag manager, and portfolio/resume links.
3. **🔍 Search & Filter Internships:** Real-time keyword search, category pills (Software Engineering, Frontend, Backend, AI/ML, UI/UX), workplace type filter (Remote, Hybrid, On-site), and multiple sorting options.
4. **⚡ Apply for Jobs:** 1-click apply modal with auto-filled profile and customizable cover letter, guarded by duplicate submission protection.
5. **📋 Track Application Status:** Multi-stage visual pipeline tracker (`Applied` ➔ `Under Review` ➔ `Shortlisted` ➔ `Interview Scheduled` ➔ `Accepted` / `Rejected`), status color badges, and recruiter feedback notes.
